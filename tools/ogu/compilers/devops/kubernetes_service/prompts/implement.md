# Kubernetes Service Compiler — Implementation Guide

## Purpose

Define a Kubernetes Service that correctly routes traffic to a workload. A Service with no
selector routes to nothing. A LoadBalancer Service without cloud annotations becomes a
public internet-facing load balancer by default — regardless of what you intended. A Service
in the `default` namespace applies no namespace-scoped RBAC, making access control impossible.
This compiler enforces the full correctness chain before emitting an artifact.

## Invariants

| Code  | Gate                  | What It Enforces |
|-------|-----------------------|------------------|
| KS001 | spec-valid            | `k8s-service-spec.json` exists, is valid JSON; `name`, `selector`, and a non-empty `ports` array are required |
| KS002 | selector-resolves     | Service selector labels match a known workload artifact in the project (skipped when no workload artifact is present) |
| KS003 | ports-valid           | Every port entry has a valid `port` (1–65535), a `targetPort` or name, and an optional `protocol` from `TCP`/`UDP`/`SCTP` |
| KS004 | no-duplicate-ports    | No two ports entries share the same `port` number — the API server rejects duplicates |
| KS005 | service-type-allowed  | `type` is one of `ClusterIP`, `NodePort`, `LoadBalancer`, `ExternalName`, `Headless`. `LoadBalancer` and `NodePort` carry operational warnings |
| KS006 | no-todos              | `k8s-service-spec.json` contains no `TODO`, `FIXME`, `HACK`, `XXX`, or `PLACEHOLDER` markers |
| KS007 | contract-k8s-service  | `namespace` must be declared; `LoadBalancer` Services must include cloud-specific `annotations` |

## Required Output Files

- `k8s-service-spec.json` — Service declaration (name, namespace, type, selector, ports)
- `k8s-service-artifact.json` — generated by the compiler on full gate pass

## k8s-service-spec.json Structure

```json
{
  "name": "api-service",
  "namespace": "production",
  "type": "ClusterIP",
  "selector": { "app": "api" },
  "ports": [
    { "name": "http",  "port": 80,   "targetPort": 3000, "protocol": "TCP" },
    { "name": "https", "port": 443,  "targetPort": 3443, "protocol": "TCP" }
  ]
}
```

LoadBalancer example with annotations (required by KS007):
```json
{
  "name": "api-lb",
  "namespace": "production",
  "type": "LoadBalancer",
  "selector": { "app": "api" },
  "ports": [{ "port": 443, "targetPort": 3443, "protocol": "TCP" }],
  "annotations": {
    "service.beta.kubernetes.io/aws-load-balancer-internal": "true",
    "service.beta.kubernetes.io/aws-load-balancer-type": "nlb"
  }
}
```

| Field         | Required     | Notes |
|---------------|--------------|-------|
| `name`        | yes          | Used in IR ID: `K8S_SERVICE:{namespace}/{name}` |
| `namespace`   | yes (KS007)  | Declaring `default` is valid but strongly discouraged |
| `type`        | no           | Defaults to `ClusterIP`; enum: `ClusterIP`, `NodePort`, `LoadBalancer`, `ExternalName`, `Headless` |
| `selector`    | yes          | Must match pod labels of the target workload |
| `ports`       | yes          | Non-empty array; each entry needs `port` and `targetPort` |
| `annotations` | conditional  | Required when `type` is `LoadBalancer` |

## Error Codes

| Code  | Trigger | Fix |
|-------|---------|-----|
| KS001 | `k8s-service-spec.json` missing | Create the file with `name`, `selector`, and `ports` |
| KS001 | `ports` is empty array | Add at least one port entry |
| KS002 | Selector has no matching workload | Ensure `selector` labels match labels in a compiled workload artifact |
| KS003 | `port: 99999` | Port must be 1–65535 |
| KS003 | Missing `targetPort` | Add `targetPort: 3000` (the container port the Service forwards to) |
| KS003 | `protocol: "HTTP"` | Protocol must be `TCP`, `UDP`, or `SCTP` |
| KS004 | Two entries both using `port: 80` | Give each port a unique number; use `name` to differentiate |
| KS005 | `type: "ExternalLoad"` | Use `ClusterIP`, `NodePort`, `LoadBalancer`, `ExternalName`, or `Headless` |
| KS007 | No `namespace` | Add `namespace: "my-service"` |
| KS007 | `LoadBalancer` with no `annotations` | Add cloud annotations to prevent unintended public exposure |
