# Kubernetes Workload Compiler — Implementation Guide

## Purpose

Define a production-safe Kubernetes workload (Deployment, StatefulSet, or DaemonSet).
A workload without resource limits is a shared-cluster liability — one memory leak OOM-kills
neighbouring pods. A workload without probes sends traffic to containers that crashed on
startup. A workload with a floating image tag deploys a different version on every node.
This compiler enforces the full set of production requirements before emitting an artifact.

## Invariants

| Code  | Gate                      | What It Enforces |
|-------|---------------------------|------------------|
| KW001 | spec-valid                | `k8s-workload-spec.json` exists, is valid JSON; `kind` is one of `Deployment`/`StatefulSet`/`DaemonSet`; `replicas` is a non-negative integer |
| KW002 | selector-labels-match     | Every label in `selectorLabels` must also appear in `podLabels` — Kubernetes rejects mismatches at apply time |
| KW003 | containers-have-resources | Every container declares `requests.cpu`, `requests.memory`, and `limits.memory` — missing requests disable scheduler placement; missing limits allow OOM eviction of other pods |
| KW004 | image-refs-valid          | No image uses `:latest`, `:dev`, `:main`, `:master`, `:edge`, `:stable`, `:nightly`, `:canary`, or an implicit (no-tag) reference |
| KW005 | refs-declared             | All `ConfigMap` and `Secret` references in `envFrom` and `volumes` are listed in `spec.declaredRefs` — undeclared refs produce `CrashLoopBackOff` with no useful error |
| KW006 | rollout-strategy-valid    | `strategy.type` is `RollingUpdate` or `Recreate`; `maxSurge`/`maxUnavailable` are non-negative integers or `"25%"`-style strings. Skipped for DaemonSet |
| KW007 | no-todos                  | `k8s-workload-spec.json` contains no `TODO`, `FIXME`, `HACK`, `XXX`, or `PLACEHOLDER` markers |
| KW008 | contract-k8s-workload     | `livenessProbe` and `readinessProbe` are defined; `namespace` is declared; single-replica Deployments without HPA flag a downtime risk |

## Required Output Files

- `k8s-workload-spec.json` — workload declaration (kind, image, replicas, resources, probes)
- `k8s-workload-artifact.json` — generated by the compiler on full gate pass

## k8s-workload-spec.json Structure

```json
{
  "name": "api",
  "kind": "Deployment",
  "namespace": "production",
  "image": "my-registry/api:1.4.2",
  "replicas": 2,
  "selectorLabels": { "app": "api", "version": "1.4.2" },
  "podLabels":      { "app": "api", "version": "1.4.2", "tier": "backend" },
  "resources": {
    "requests": { "cpu": "100m", "memory": "128Mi" },
    "limits":   { "memory": "256Mi" }
  },
  "livenessProbe": {
    "httpGet": { "path": "/health", "port": 3000 },
    "initialDelaySeconds": 10,
    "periodSeconds": 30
  },
  "readinessProbe": {
    "httpGet": { "path": "/ready", "port": 3000 },
    "initialDelaySeconds": 5,
    "periodSeconds": 10
  },
  "strategy": {
    "type": "RollingUpdate",
    "rollingUpdate": { "maxSurge": 1, "maxUnavailable": 0 }
  },
  "declaredRefs": [
    { "kind": "ConfigMap", "name": "api-config" },
    { "kind": "Secret",    "name": "api-secrets" }
  ],
  "envFrom": [
    { "configMapRef": { "name": "api-config" } },
    { "secretRef":    { "name": "api-secrets" } }
  ]
}
```

| Field            | Required     | Notes |
|------------------|--------------|-------|
| `name`           | yes          | Used in IR ID: `K8S_WORKLOAD:{namespace}/{kind}/{name}` |
| `kind`           | yes          | Enum: `Deployment`, `StatefulSet`, `DaemonSet` |
| `namespace`      | yes (KW008)  | Declaring `default` is valid but flagged as antipattern |
| `image`          | yes          | Must include a pinned tag or SHA digest |
| `replicas`       | yes          | Integer ≥ 0 (`0` = scaled down) |
| `resources`      | yes (KW003)  | `requests.cpu`, `requests.memory`, `limits.memory` all required |
| `livenessProbe`  | yes (KW008)  | Or `probes.liveness` |
| `readinessProbe` | yes (KW008)  | Or `probes.readiness` |
| `declaredRefs`   | conditional  | Required when `envFrom` or `volumes` reference ConfigMaps/Secrets |
| `strategy`       | no           | Defaults to Kubernetes RollingUpdate when omitted |

## Error Codes

| Code  | Trigger | Fix |
|-------|---------|-----|
| KW001 | `k8s-workload-spec.json` missing | Create the file with at minimum `name`, `kind`, `image`, `replicas` |
| KW001 | `kind: "Job"` | Use `Deployment`, `StatefulSet`, or `DaemonSet` |
| KW001 | `replicas: -1` | Must be `0` or a positive integer |
| KW002 | Selector label absent from pod labels | Add the label to `podLabels`, or remove it from `selectorLabels` |
| KW003 | Missing `resources.requests.cpu` | Add `resources: { requests: { cpu: "100m", memory: "128Mi" }, limits: { memory: "256Mi" } }` |
| KW003 | Missing `resources.limits.memory` | Memory limit is required; CPU limit is optional |
| KW004 | `image: my-app:latest` | Pin to `my-app:1.4.2` or use a SHA digest |
| KW004 | `image: my-app:main` | `:main` is mutable — use a semantic version tag |
| KW005 | ConfigMap referenced but not in `declaredRefs` | Add `{ "kind": "ConfigMap", "name": "api-config" }` to `spec.declaredRefs` |
| KW006 | `strategy.type: "BlueGreen"` | Only `RollingUpdate` and `Recreate` are valid |
| KW006 | `maxSurge: "two"` | Use an integer (`1`) or percentage string (`"25%"`) |
| KW008 | No `livenessProbe` | Add `livenessProbe: { httpGet: { path: "/health", port: 3000 }, initialDelaySeconds: 10 }` |
| KW008 | No `readinessProbe` | Add `readinessProbe: { httpGet: { path: "/ready", port: 3000 }, initialDelaySeconds: 5 }` |
| KW008 | No `namespace` | Add `namespace: "my-service"` |
| KW008 | Single replica, no HPA | Set `replicas: 2`, or define `hpa: { minReplicas: 2, maxReplicas: 10 }` |
