# Dockerfile Image Compiler — Implementation Guide

## Purpose

Build a production-safe container image configuration. A Dockerfile with a floating base tag
or root-user execution is a security incident waiting to happen: CVE patches in `:latest`
introduce breaking changes on rebuild, and root containers allow container escape if the
runtime is compromised. This compiler enforces the full chain — from a parseable spec to a
deterministic, hardened Dockerfile.

## Invariants

| Code  | Gate                   | What It Enforces |
|-------|------------------------|------------------|
| DF001 | spec-valid             | `dockerfile-spec.json` exists, is valid JSON, declares `runtime` (from allowed enum), `entrypoint`, and `ports` (integers 1–65535) |
| DF002 | dockerfile-exists      | A `Dockerfile` (or `Dockerfile.prod`, `Dockerfile.production`) is present in the build context |
| DF003 | single-entrypoint      | The final stage has exactly one `CMD` or `ENTRYPOINT` — duplicates are silently collapsed by Docker and indicate unclear intent |
| DF004 | base-image-pinned      | Every `FROM` uses a pinned version tag or SHA digest — `:latest`, `:dev`, `:main`, `:master`, `:edge`, and bare names (no tag) are rejected |
| DF005 | non-root               | A `USER` instruction exists and does not set `root` or uid `0` |
| DF006 | no-secrets-in-build    | No `ARG`/`ENV` lines embed a secret-looking value — detection requires both a suspicious name (password, secret, token, key) AND a real value (not a placeholder) |
| DF007 | dockerignore-present   | `.dockerignore` exists; advisory check recommends `.git`, `node_modules`, `.env`, `*.log` |
| DF008 | ports-match-spec       | Every port in `spec.ports` has a matching `EXPOSE` instruction (skipped if `spec.ports` is empty) |
| DF009 | no-todos               | `dockerfile-spec.json` contains no `TODO`, `FIXME`, `HACK`, `XXX`, or `PLACEHOLDER` markers |
| DF010 | contract-dockerfile    | `HEALTHCHECK` and `WORKDIR` are declared; local file copies use `COPY` not `ADD` |

## Required Output Files

- `dockerfile-spec.json` — declares the service runtime, ports, and entrypoint
- `Dockerfile` — the container build definition
- `.dockerignore` — build context exclusion list
- `dockerfile-artifact.json` — generated by the compiler on full gate pass

## dockerfile-spec.json Structure

```json
{
  "service": "api",
  "runtime": "node",
  "baseImage": "node:20.11.1-alpine",
  "entrypoint": "dist/server.js",
  "ports": [3000, 9229],
  "packageManager": "npm",
  "user": "appuser"
}
```

| Field          | Required | Notes |
|----------------|----------|-------|
| `runtime`      | yes      | Enum: `node`, `python`, `go`, `java`, `ruby`, `rust`, `dotnet`, `php`, `bun`, `deno` |
| `entrypoint`   | yes      | Entry command string |
| `ports`        | yes      | Array of integers 1–65535 (can be empty array) |
| `service`      | no       | Used in IR ID (`DOCKERFILE:{service}`) |
| `baseImage`    | no       | Informational — actual pinning is enforced in the Dockerfile itself |
| `packageManager` | no    | `npm`, `yarn`, `pnpm`, `pip`, `poetry`, etc. |
| `user`         | no       | Informational — actual USER instruction is enforced in the Dockerfile |

## Dockerfile Pattern

```dockerfile
FROM node:20.11.1-alpine AS base
WORKDIR /app

FROM base AS deps
COPY package*.json ./
RUN npm ci --omit=dev

FROM base AS release
COPY --from=deps /app/node_modules ./node_modules
COPY dist/ ./dist/

RUN addgroup -S appgroup && adduser -S appuser -G appgroup
USER appuser

EXPOSE 3000
HEALTHCHECK --interval=30s --timeout=5s --retries=3 \
  CMD wget -qO- http://localhost:3000/health || exit 1

CMD ["node", "dist/server.js"]
```

## Error Codes

| Code  | Trigger | Fix |
|-------|---------|-----|
| DF001 | `dockerfile-spec.json` missing or invalid JSON | Create the file; run `node -e "JSON.parse(fs.readFileSync('dockerfile-spec.json','utf8'))"` to find syntax errors |
| DF001 | `runtime` not in allowed enum | Use one of: `node`, `python`, `go`, `java`, `ruby`, `rust`, `dotnet`, `php`, `bun`, `deno` |
| DF001 | `ports` contains non-integer or out-of-range value | Ports must be integers between 1 and 65535 |
| DF002 | No Dockerfile found | Create `Dockerfile` in the build context root |
| DF003 | No CMD/ENTRYPOINT in final stage | Add `CMD ["node", "dist/server.js"]` or `ENTRYPOINT` |
| DF003 | Multiple CMD instructions | Remove all but the last; use `ENTRYPOINT + CMD` pattern for parameterisable images |
| DF004 | `FROM node:latest` or `FROM node` (no tag) | Pin to `FROM node:20.11.1-alpine` or a SHA digest |
| DF005 | No USER instruction | Add `RUN addgroup -S app && adduser -S app -G app` then `USER app` |
| DF005 | `USER root` or `USER 0` | Change to a non-root user before the final CMD |
| DF006 | `ENV DB_PASSWORD=realpassword` | Remove the value from the Dockerfile; inject at runtime via `--secret`, k8s Secrets, or Vault |
| DF007 | `.dockerignore` not found | Create `.dockerignore`; at minimum add `.git`, `node_modules`, `.env`, `*.log` |
| DF008 | Port in spec not EXPOSE'd | Add `EXPOSE 3000` (matching spec.ports) to the Dockerfile |
| DF009 | TODO/FIXME in spec | Fill in real values before compiling |
| DF010 | No HEALTHCHECK | Add `HEALTHCHECK --interval=30s CMD wget -qO- http://localhost:${PORT}/health \|\| exit 1` |
| DF010 | No WORKDIR | Add `WORKDIR /app` before any COPY or RUN instruction |
| DF010 | ADD used for local file | Replace `ADD ./src .` with `COPY ./src .` |
