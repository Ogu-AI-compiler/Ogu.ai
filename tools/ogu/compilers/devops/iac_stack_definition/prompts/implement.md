# IaC Stack Definition — Implementation Guide

## Purpose

Define an infrastructure stack that is reproducible, team-safe, and auditable. Local Terraform state
cannot be shared across engineers or CI — concurrent applies will corrupt it. A module or provider
without a pinned version silently changes behaviour on the next `terraform init`. A hardcoded access
key in a `.tf` file is committed to source control and preserved in git history indefinitely. A stack
with only a production environment gives engineers no safe place to validate changes before they
affect live traffic. This compiler enforces all of these constraints before emitting an artifact.

## Invariants

| Code   | Gate                     | What It Enforces |
|--------|--------------------------|------------------|
| IAC001 | spec-valid               | `iac-spec.json` exists, is valid JSON; `platform` and `cloud` are from the supported enums; `environments` is non-empty; `stateBackend` is declared |
| IAC002 | inputs-declared          | Terraform: every spec input has a typed `variable` block in `.tf` files; Pulumi/CDK: inputs must declare `type` in spec (skipped when no inputs) |
| IAC003 | outputs-declared         | Terraform: every spec output has a matching `output` block in `.tf` files — missing outputs break downstream consumers (skipped when no outputs) |
| IAC004 | no-unresolved-refs       | Terraform: every `module` block must declare a `source` attribute — missing source causes `terraform init` to fail |
| IAC005 | no-hardcoded-credentials | All IaC files (`.tf`, `.yaml`, `.ts`, `.py`) must not contain literal credentials matching known patterns (access key, secret key, AKIA*) |
| IAC006 | provider-allowed         | Terraform: all providers in `required_providers` must be on the approved list for the target cloud (skipped for non-Terraform) |
| IAC007 | no-todos                 | `iac-spec.json` contains no `TODO`, `FIXME`, `HACK`, `XXX`, or `PLACEHOLDER` markers |
| IAC008 | contract-iac             | `stateBackend` is non-empty; `environments` includes both a production env and a non-production env; all object inputs have `description` |

## Required Output Files

- `iac-spec.json` — author-maintained stack declaration
- `iac-artifact.json` — generated by the compiler on full gate pass

## iac-spec.json Structure

```json
{
  "platform": "terraform",
  "cloud": "aws",
  "environments": ["staging", "production"],
  "stateBackend": "s3://my-tf-state-bucket/api-gateway",
  "inputs": [
    {
      "name": "region",
      "type": "string",
      "default": "us-east-1",
      "description": "AWS region where all resources are deployed"
    },
    {
      "name": "instance_count",
      "type": "number",
      "default": 2,
      "description": "Number of EC2 instances in the ASG"
    },
    {
      "name": "db_password",
      "type": "string",
      "description": "RDS master password — injected via CI secret, never committed"
    }
  ],
  "outputs": [
    { "name": "vpc_id",          "description": "VPC created for this stack" },
    { "name": "load_balancer_dns", "description": "Public DNS name of the ALB" }
  ]
}
```

## Field Reference

| Field            | Required    | Notes |
|------------------|-------------|-------|
| `platform`       | yes (IAC001)| See platform reference table below |
| `cloud`          | yes (IAC001)| See cloud reference table below |
| `environments`   | yes (IAC001)| Non-empty; must include production AND a non-prod env |
| `stateBackend`   | yes (IAC001/IAC008) | Non-empty string: S3 URL, GCS path, `"azurerm"`, or Terraform Cloud workspace |
| `inputs`         | no          | Array of `{ name, type, description }` objects; all must have `description` (IAC008) |
| `inputs[].type`  | yes if object| Required for type validation in IAC002 |
| `outputs`        | no          | Array of `{ name, description }` — Terraform: must have matching `output` blocks |

## Platform Reference

| Platform     | State Backend Format | Input Declaration | Provider Pinning |
|--------------|---------------------|-------------------|------------------|
| `terraform`  | `s3://bucket/path`, `gcs://bucket/path`, `azurerm` | `variables.tf` variable blocks | `required_providers` with version constraints |
| `pulumi`     | Pulumi Cloud workspace or S3/GCS | Config schema in code | Package versions in `package.json` / `go.mod` |
| `cdk`        | CloudFormation backend | CDK context / props | CDK library versions in `package.json` |
| `ansible`    | Inventory / AWX | `vars:` blocks | Collection versions in `requirements.yml` |
| `crossplane`  | Kubernetes etcd | Composition spec inputs | Provider package versions |

## Cloud Reference

| Cloud          | Approved Terraform Providers |
|----------------|------------------------------|
| `aws`          | aws, archive, null, random, local, tls |
| `gcp`          | google, google-beta, archive, null, random |
| `azure`        | azurerm, azuread, archive, null, random |
| `digitalocean` | digitalocean, archive, null, random |
| `cloudflare`   | cloudflare, archive, null, random |
| `multi`        | aws, google, azurerm, archive, null, random, tls, local |

## State Backend Reference

| Cloud  | Backend Format |
|--------|----------------|
| AWS    | `"s3://my-state-bucket/path/to/stack"` |
| GCP    | `"gcs://my-state-bucket/path/to/stack"` |
| Azure  | `"azurerm"` with config in `backend.tf` |
| TF Cloud | `"app.terraform.io/org/workspace"` |

## Error Codes

| Code   | Trigger | Fix |
|--------|---------|-----|
| IAC001 | `iac-spec.json` missing | Create the file with `platform`, `cloud`, `environments`, `stateBackend` |
| IAC001 | `platform: "cloudformation"` | Not supported — use `terraform`, `pulumi`, `cdk`, `ansible`, or `crossplane` |
| IAC001 | `cloud: "oracle"` | Not supported — use `aws`, `gcp`, `azure`, `digitalocean`, `cloudflare`, or `multi` |
| IAC001 | `environments: "production"` (string) | Must be an array: `["staging", "production"]` |
| IAC002 | Input `db_password` declared but no `variable "db_password"` in `.tf` | Add `variable "db_password" { type = string }` to `variables.tf` |
| IAC002 | Input object with no `type` | Add `"type": "string"` (or number/boolean) to the input entry |
| IAC003 | Output `vpc_id` declared but no `output "vpc_id"` in `.tf` | Add `output "vpc_id" { value = aws_vpc.main.id }` to `outputs.tf` |
| IAC004 | Module block `module "vpc" {}` with no `source` | Add `source = "terraform-aws-modules/vpc/aws"` to the module block |
| IAC005 | `secret_key = "ABCD1234EFGH5678IJKL"` in `provider.tf` | Remove the literal — use `var.secret_key` and inject via CI or AWS role |
| IAC005 | `AKIAIOSFODNN7EXAMPLE` in any `.tf` file | Remove the AWS access key — rotate immediately and use IAM roles instead |
| IAC006 | `kubernetes` provider declared for `cloud: "aws"` | Not in the approved list — raise a review request or use the approved EKS config approach |
| IAC008 | `stateBackend: ""` | Set to a non-empty backend path — local state is not allowed for team environments |
| IAC008 | `environments: ["production"]` | Add a non-production environment: `["staging", "production"]` |
| IAC008 | `environments: ["dev", "staging"]` | Add a production environment: `["dev", "staging", "production"]` |
| IAC008 | Input object with no `description` | Add `"description": "What this input controls and where it comes from"` |
