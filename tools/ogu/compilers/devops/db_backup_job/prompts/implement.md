# DB Backup Job — Implementation Guide

## Purpose

Define a database backup job that produces verifiable, encrypted backups with a bounded retention
policy. A backup without a checksum cannot be confirmed as uncorrupted — you only discover the
backup is invalid when you try to restore during an incident. A backup without a retention policy
accumulates indefinitely, filling storage until the backup process itself fails. Backups without
encryption expose the entire database at rest to anyone who gains storage access. This compiler
enforces all of these constraints before emitting an artifact.

## Invariants

| Code   | Gate                   | What It Enforces |
|--------|------------------------|------------------|
| DBB001 | spec-valid             | `db-backup-spec.json` exists, is valid JSON; `command`, `destination`, `schedule`, and `retentionCount` are declared |
| DBB002 | schedule-valid         | `schedule` is a valid 5-field cron expression or a recognised shorthand |
| DBB003 | retention-set          | At least one of `retentionCount` or `retentionDays` is declared as a positive integer |
| DBB004 | checksum-generation    | Checksum generation must be enabled to verify backup integrity after upload |
| DBB005 | no-literal-credentials | No literal credentials in the spec — DB URLs and storage keys must reference env vars |
| DBB006 | no-todos               | `db-backup-spec.json` contains no `TODO`, `FIXME`, `HACK`, `XXX`, or `PLACEHOLDER` markers |
| DBB007 | contract-db-backup     | Encryption must be configured (`encryptionEnabled: true` or `encryptionKey`); storage destination must be declared |

## Required Output Files

- `db-backup-spec.json` — author-maintained backup job declaration
- `db-backup-artifact.json` — generated by the compiler on full gate pass

## db-backup-spec.json Structure

```json
{
  "command": "pg_dump",
  "destination": "s3://my-backups/postgres/",
  "schedule": "0 3 * * *",
  "retentionCount": 7,
  "retentionDays": 30,
  "checksumAlgorithm": "sha256",
  "encryptionEnabled": true,
  "storageDestination": "s3://my-backups/postgres/",
  "credentials": {
    "dbUrl":      { "envVar": "DATABASE_URL" },
    "storageKey": { "envVar": "S3_SECRET_KEY" }
  }
}
```

## Field Reference

| Field                 | Required     | Notes |
|-----------------------|--------------|-------|
| `command`             | yes (DBB001) | Backup tool: `pg_dump`, `mongodump`, `mysqldump`, etc. |
| `destination`         | yes (DBB001) | Remote storage path — avoid local paths |
| `schedule`            | yes (DBB001) | 5-field cron or shorthand |
| `retentionCount`      | conditional  | Number of backups to keep (DBB003 requires this or `retentionDays`) |
| `retentionDays`       | conditional  | Days to retain backups |
| `checksumAlgorithm`   | yes (DBB004) | `sha256`, `md5`, or equivalent |
| `encryptionEnabled`   | conditional  | `true` to flag encryption is on (DBB007) |
| `encryptionKey`       | conditional  | KMS key reference — alternative to `encryptionEnabled` |
| `skipEncryptionCheck` | no           | `true` if encryption is at the storage layer |
| `storageDestination`  | conditional  | Explicit storage path for DBB007 audit |
| `storageClass`        | conditional  | Alternative to `storageDestination` |

## Error Codes

| Code   | Trigger | Fix |
|--------|---------|-----|
| DBB001 | `db-backup-spec.json` missing | Create the file with `command`, `destination`, `schedule`, `retentionCount` |
| DBB002 | `schedule: "0 3 * * * *"` (6 fields) | Cron needs exactly 5 fields: `"0 3 * * *"` |
| DBB002 | `schedule: "0 26 * * *"` | Hour 26 is out of range 0–23 |
| DBB003 | No `retentionCount` and no `retentionDays` | Add `retentionCount: 7` or `retentionDays: 30` |
| DBB003 | `retentionDays: 0` | Must be a positive integer — use at least `1` |
| DBB004 | No `checksumAlgorithm` | Add `checksumAlgorithm: "sha256"` |
| DBB005 | `credentials: { dbUrl: "postgres://user:pass@host/db" }` | Replace with `{ envVar: "DATABASE_URL" }` |
| DBB007 | No `encryptionEnabled` and no `encryptionKey` | Add `encryptionEnabled: true` or `encryptionKey: "arn:aws:kms:..."` |
| DBB007 | No `storageDestination` or `storageClass` | Add `storageDestination: "s3://my-backups/postgres/"` |
