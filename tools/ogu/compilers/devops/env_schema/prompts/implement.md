# Env Schema — Implementation Guide

## Purpose

Define every environment variable a service reads, with an explicit type, optionality declaration,
and secret classification. A key without a type cannot be validated at startup — the service accepts
anything and crashes later with a confusing error. A key with `secret: true` and a `default` value
commits a credential into source control and every container layer derived from that image. A key
with no `required` or `default` is ambiguous — the runtime does not know whether to reject the
startup or silently continue. This compiler enforces all of these constraints before emitting an
artifact.

## Invariants

| Code  | Gate                | What It Enforces |
|-------|---------------------|------------------|
| ES001 | spec-valid          | `env-schema-spec.json` exists, is valid JSON; `envKeys` is non-empty; `unknownKeyPolicy` is `reject` or `ignore`; each key has `name` and a recognised `type` |
| ES002 | unique-names        | No two entries in `envKeys` share the same `name` — duplicates cause silent last-wins semantics |
| ES003 | type-valid          | Every key declares a valid `type` and must have either `required: true` or a `default` — keys with neither are ambiguous |
| ES004 | defaults-typed      | Default values must conform to the key's declared type — a mistyped default fails at startup with no spec-time warning |
| ES005 | no-secret-default   | Keys with `secret: true` must not carry literal defaults in the spec or literal values in committed `.env` files (`.env.example` excluded) |
| ES006 | no-todos            | `env-schema-spec.json` contains no `TODO`, `FIXME`, `HACK`, `XXX`, or `PLACEHOLDER` markers |
| ES007 | contract-env-schema | All keys must have a non-empty `description`; `required: true` keys must not also declare a `default` |

## Required Output Files

- `env-schema-spec.json` — author-maintained list of all environment variables the service reads
- `env-schema-artifact.json` — generated by the compiler on full gate pass

## env-schema-spec.json Structure

```json
{
  "service": "api-gateway",
  "unknownKeyPolicy": "reject",
  "envKeys": [
    {
      "name": "DATABASE_URL",
      "type": "url",
      "required": true,
      "secret": true,
      "description": "Primary Postgres connection string — injected via k8s Secret"
    },
    {
      "name": "PORT",
      "type": "port",
      "default": 3000,
      "description": "HTTP listen port — defaults to 3000 in local dev"
    },
    {
      "name": "LOG_LEVEL",
      "type": "string",
      "default": "info",
      "description": "Logging verbosity: debug, info, warn, error"
    },
    {
      "name": "REDIS_URL",
      "type": "url",
      "required": true,
      "secret": true,
      "description": "Redis connection string for session and cache — injected at deploy time"
    },
    {
      "name": "FEATURE_FLAG_ROLLOUT",
      "type": "boolean",
      "default": false,
      "description": "Enable experimental rollout feature — off by default until QA sign-off"
    }
  ]
}
```

## Field Reference

| Field             | Required   | Notes |
|-------------------|------------|-------|
| `service`         | no         | Label for the owning service — used in artifact IR ID |
| `unknownKeyPolicy`| yes (ES001)| `reject` = fail when unknown env vars present; `ignore` = silently allow them |
| `envKeys`         | yes (ES001)| Non-empty array; each entry needs `name`, `type`, and optionality |
| `envKeys[].name`  | yes        | The exact env var name — must be unique across the array |
| `envKeys[].type`  | yes (ES001)| See type reference table below |
| `envKeys[].required`| conditional| Must be `true` OR `default` must be set — not both for `required: true` |
| `envKeys[].default` | conditional| Must conform to the declared `type` (ES004); forbidden for `secret: true` keys |
| `envKeys[].secret`  | no         | `true` = no literal defaults allowed; no committed `.env` values |
| `envKeys[].description` | yes (ES007) | Non-empty human-readable description for operator reference |

## Type Reference

| Type      | Validated By | Example Default |
|-----------|--------------|-----------------|
| `string`  | `typeof === 'string'` | `"info"` |
| `number`  | Coercible to `Number` | `8080` |
| `boolean` | `true`/`false` or strings `"true"`/`"false"` | `false` |
| `port`    | Integer 1–65535 | `3000` |
| `url`     | `new URL()` succeeds | `"http://localhost:5432/db"` |
| `email`   | Matches `[^@]+@[^@]+\.[^@]+` | `"ops@example.com"` |
| `json`    | `JSON.parse()` succeeds | `"{}"` |
| `base64`  | Matches base64 character set | `"dGVzdA=="` |

## Error Codes

| Code  | Trigger | Fix |
|-------|---------|-----|
| ES001 | `env-schema-spec.json` missing | Create the file with `envKeys` and `unknownKeyPolicy` |
| ES001 | `envKeys` is empty | Add at least one key to the array |
| ES001 | `unknownKeyPolicy: "fail"` | Must be `"reject"` or `"ignore"` |
| ES001 | Key with `type: "integer"` | Use `"number"` — `integer` is not a recognised type |
| ES002 | Two keys both named `DATABASE_URL` | Remove the duplicate or rename one |
| ES003 | Key with no `required` and no `default` | Add `required: true` or a `default` value |
| ES004 | `type: "port"`, `default: "http://localhost"` | Fix default to an integer like `3000`, or change type to `"url"` |
| ES004 | `type: "boolean"`, `default: "yes"` | Use `true` or `false` (not `"yes"`) |
| ES005 | `secret: true` with `default: "my-secret-value"` | Remove the `default` — inject secrets at runtime via k8s Secret or Vault |
| ES005 | `.env.production` contains `DATABASE_URL=postgres://user:pass@...` | Remove literal credentials from committed files |
| ES007 | Key with no `description` | Add `description: "What this variable controls and where it comes from"` |
| ES007 | `required: true` with `default: "fallback"` | Remove `default` — a required key must not have a fallback |
