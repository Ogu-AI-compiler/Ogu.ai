# Developer Platform Stack — Implementation Guide

## Purpose

A developer platform without an artifact registry means built images have no canonical location
— deployments reference local builds that only exist on a developer's machine. Without golden
paths, every team invents their own project structure, CI pipeline, and deployment process —
creating inconsistency that scales into chaos. Without an IDP (Internal Developer Portal),
the platform's capabilities are undiscoverable — engineers write documentation that no one
reads because there is no single place to find it. Without SBOM coverage, a newly published
CVE cannot be traced to which services are affected — you learn about it from customers.
Two `ci-cd` components without `multi: true` creates ambiguity about which pipeline is
authoritative — both are used, configuration drifts, and neither is maintained properly.
This compiler enforces all of these constraints before emitting an artifact.

## Invariants

| Code  | Gate                    | What It Enforces |
|-------|-------------------------|------------------|
| DP001 | spec-valid              | `dev-platform-spec.json` exists, is valid JSON; `name` and `components` (non-empty) are declared |
| DP002 | components-known        | Every `components[].type` is in the recognised platform component allowlist |
| DP003 | golden-paths-defined    | At least one golden path with `name` and `steps` is defined (overridable with `skipGoldenPaths: true`) |
| DP004 | idp-integrated          | An `idp` component with a `tool` field is present (overridable with `skipIDPCheck: true`) |
| DP005 | sbom-coverage           | An `sbom` component is present for supply chain integrity (overridable with `skipSBOM: true`) |
| DP006 | no-todos                | `dev-platform-spec.json` contains no `TODO`, `FIXME`, `HACK`, `XXX`, or `PLACEHOLDER` |
| DP007 | contract-dev-platform   | `source-control`, `ci-cd`, and `artifact-registry` components all present; no duplicate types unless `multi: true` |

## Required Output Files

- `dev-platform-spec.json` — author-maintained platform declaration
- `dev-platform-artifact.json` — generated by the compiler on full gate pass

## dev-platform-spec.json Structure

```json
{
  "name": "acme-developer-platform",
  "components": [
    { "type": "source-control",    "tool": "github",    "url": "https://github.com/acme" },
    { "type": "ci-cd",             "tool": "buildkite", "url": "https://buildkite.com/acme" },
    { "type": "artifact-registry", "tool": "ecr",       "url": "https://ecr.aws.com/acme" },
    { "type": "idp",               "tool": "backstage", "url": "https://backstage.acme.internal" },
    { "type": "sbom",              "tool": "syft",      "format": "cyclonedx" },
    { "type": "observability",     "tool": "datadog",   "url": "https://app.datadoghq.com" }
  ],
  "goldenPaths": [
    {
      "name": "create-node-service",
      "steps": ["scaffold", "configure-ci", "add-dockerfile", "deploy-to-staging"]
    },
    {
      "name": "promote-to-production",
      "steps": ["run-smoke-tests", "approve-promotion", "deploy-production", "verify-health"]
    }
  ]
}
```

## Field Reference

| Field                    | Required    | Notes |
|--------------------------|-------------|-------|
| `name`                   | yes (DP001) | Platform identifier |
| `components`             | yes (DP001) | Non-empty array of platform tool/service configurations |
| `components[].type`      | yes (DP002) | Must be a recognised component type |
| `components[].tool`      | no          | Specific tool used (e.g. `"github"`, `"backstage"`) |
| `components[].multi`     | no          | `true` to allow multiple instances of the same type |
| `goldenPaths`            | yes (DP003) | Array of developer workflow definitions |
| `goldenPaths[].name`     | yes (DP003) | Workflow identifier |
| `goldenPaths[].steps`    | yes (DP003) | Non-empty array of step strings |
| `skipGoldenPaths`        | no          | `true` to exempt from DP003 |
| `skipIDPCheck`           | no          | `true` to exempt from DP004 |
| `skipSBOM`               | no          | `true` to exempt from DP005 |

## Component Type Reference

| Type                  | Role |
|-----------------------|------|
| `source-control`      | Git hosting (GitHub, GitLab, Bitbucket) — **required** |
| `ci-cd`               | Pipeline execution (Buildkite, GitHub Actions, Jenkins) — **required** |
| `artifact-registry`   | Image/package storage (ECR, Artifact Registry, Nexus) — **required** |
| `idp`                 | Internal Developer Portal (Backstage, Cortex, Port) |
| `sbom`                | Software Bill of Materials (Syft, CycloneDX) |
| `observability`       | Metrics/logs/traces (Datadog, Grafana, Honeycomb) |
| `secret-manager`      | Secret storage (Vault, AWS Secrets Manager) |
| `feature-flags`       | Feature toggle management (LaunchDarkly, Unleash) |
| `gitops`              | Continuous deployment (ArgoCD, Flux) |
| `service-mesh`        | Traffic management (Istio, Linkerd) |
| `cost-attribution`    | Cloud cost tracking (AWS Cost Explorer, Infracost) |
| `oncall`              | Incident management (PagerDuty, OpsGenie) |

## Error Codes

| Code  | Trigger | Fix |
|-------|---------|-----|
| DP001 | `dev-platform-spec.json` missing | Create with `name` and `components: [...]` |
| DP001 | `components: []` | Add at least one component |
| DP002 | `type: "pipeline"` | Use `"ci-cd"` — `"pipeline"` is not a recognised type |
| DP002 | `type: "container-registry"` | Use `"artifact-registry"` |
| DP003 | No `goldenPaths` | Add `"goldenPaths": [{ "name": "create-service", "steps": ["scaffold", "deploy"] }]` |
| DP003 | Golden path missing `name` | Add `"name": "workflow-name"` |
| DP003 | Golden path `steps: []` | Add at least one step — empty steps provide no guidance |
| DP004 | No `idp` component | Add `{ "type": "idp", "tool": "backstage" }` to components |
| DP004 | IDP component missing `tool` | Add `"tool": "backstage"` (or cortex, port, etc.) |
| DP005 | No `sbom` component | Add `{ "type": "sbom", "tool": "syft", "format": "cyclonedx" }` |
| DP006 | `"tool": "TODO"` | Replace with real tool name |
| DP007 | No `source-control` component | Add `{ "type": "source-control", "tool": "github" }` |
| DP007 | No `ci-cd` component | Add `{ "type": "ci-cd", "tool": "buildkite" }` |
| DP007 | No `artifact-registry` component | Add `{ "type": "artifact-registry", "tool": "ecr" }` |
| DP007 | Two `ci-cd` components | Add `"multi": true` to each if multiple pipelines are intentional |
