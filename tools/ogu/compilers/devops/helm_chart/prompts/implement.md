# Helm Chart — Implementation Guide

## Purpose

Define a Helm chart that renders correctly, deploys real resources, and has documented ownership.
A chart with no `values.yaml` renders all `.Values.*` references as empty strings — empty image names
and missing namespace strings produce invalid Kubernetes manifests that fail silently at `helm
install`. A chart with no `templates/` deploys nothing. A `Chart.yaml` missing `apiVersion` is
rejected by `helm lint` before any template is processed. A broken `{{ }}` expression in a template
causes `helm template` to fail at deploy time, not at authoring time. This compiler enforces all
of these constraints before emitting an artifact.

## Invariants

| Code  | Gate                        | What It Enforces |
|-------|-----------------------------|------------------|
| HC001 | spec-valid                  | `helm-chart-spec.json` exists, is valid JSON; `chartName`, `version`, and `appVersion` are declared |
| HC002 | chart-yaml-valid            | `Chart.yaml` exists at the chart root and declares `name`, `version`, and `apiVersion` |
| HC003 | values-yaml-valid           | `values.yaml` exists and is non-empty — absent or empty values cause all `.Values.*` references to render as empty strings |
| HC004 | templates-render            | `templates/` directory exists and contains at least one `.yaml` or `.tpl` file |
| HC005 | no-unresolved-expressions   | Template files contain no empty `{{ }}`, TODO/PLACEHOLDER identifiers, or bare ALL-CAPS expressions that look like unsubstituted vars |
| HC006 | values-coverage             | Every top-level `.Values.<key>` reference in templates has a corresponding key in `values.yaml` |
| HC007 | no-todos                    | `helm-chart-spec.json` contains no `TODO`, `FIXME`, `HACK`, `XXX`, or `PLACEHOLDER` markers |
| HC008 | contract-helm-chart         | `maintainers` is a non-empty array and `description` is a non-empty string |

## Required Output Files

- `helm-chart-spec.json` — author-maintained chart declaration
- `Chart.yaml` — Helm chart metadata (name, version, apiVersion)
- `values.yaml` — default values for all `.Values.*` template references
- `templates/` — directory with at least one `.yaml` or `.tpl` template file
- `helm-chart-artifact.json` — generated by the compiler on full gate pass

## helm-chart-spec.json Structure

```json
{
  "chartName": "api-gateway",
  "version": "0.3.1",
  "appVersion": "1.4.2",
  "description": "API Gateway service — routes and authenticates all external traffic",
  "maintainers": [
    { "name": "Platform Team", "email": "platform@example.com" }
  ]
}
```

## Chart.yaml Structure

```yaml
apiVersion: v2
name: api-gateway
version: 0.3.1
appVersion: "1.4.2"
description: API Gateway service — routes and authenticates all external traffic
type: application
maintainers:
  - name: Platform Team
    email: platform@example.com
```

## values.yaml Structure

```yaml
image:
  repository: registry.example.com/api-gateway
  tag: "1.4.2"
  pullPolicy: IfNotPresent

replicaCount: 2

service:
  type: ClusterIP
  port: 80

resources:
  requests:
    cpu: "100m"
    memory: "128Mi"
  limits:
    memory: "512Mi"
```

## Template Expression Rules

| Expression Type | Status | Example |
|-----------------|--------|---------|
| `.Values.*` references | Allowed | `{{ .Values.image.tag }}` |
| `include "helper" .` | Allowed | `{{ include "api-gateway.fullname" . }}` |
| Conditionals | Allowed | `{{ if .Values.enabled }}` |
| Block comments | Allowed | `{{/* this is a comment */}}` |
| Empty expression | **Flagged** | `{{ }}` |
| TODO identifier | **Flagged** | `{{ TODO }}` |
| Bare ALL-CAPS | **Flagged** | `{{ MY_VAR }}` (no dot or pipe) |
| PLACEHOLDER | **Flagged** | `{{ PLACEHOLDER }}` |

## Error Codes

| Code  | Trigger | Fix |
|-------|---------|-----|
| HC001 | `helm-chart-spec.json` missing | Create the file with `chartName`, `version`, `appVersion` |
| HC001 | Missing `appVersion` | Add `appVersion: "1.4.2"` (the version of the application, not the chart) |
| HC002 | `Chart.yaml` not found | Create `Chart.yaml` with `apiVersion: v2`, `name`, and `version` |
| HC002 | `Chart.yaml` missing `apiVersion` | Add `apiVersion: v2` — required for Helm 3 charts |
| HC003 | `values.yaml` not found | Create `values.yaml` with defaults for every `.Values.*` reference in templates |
| HC003 | `values.yaml` is empty | Add at least one key-value pair |
| HC004 | `templates/` directory not found | Create `templates/` and add at least one `.yaml` file |
| HC004 | No `.yaml` or `.tpl` files in `templates/` | Add a deployment or service template |
| HC005 | `{{ }}` in `deployment.yaml` | Remove empty expressions — they cause `helm template` to fail |
| HC005 | `{{ TODO }}` in template | Replace with the actual value or a `.Values.*` reference |
| HC006 | Template references `.Values.ingress` but `ingress:` not in `values.yaml` | Add `ingress:` with default values to `values.yaml` |
| HC008 | No `maintainers` | Add `maintainers: [{ name: "Team", email: "team@example.com" }]` |
| HC008 | No `description` | Add `description: "What this chart deploys"` |
