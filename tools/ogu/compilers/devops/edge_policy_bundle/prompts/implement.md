# Edge Policy Bundle — Implementation Guide

## Purpose

A rule without a rate limit allows unlimited traffic through the edge — removing the primary
DDoS protection layer entirely. A wildcard `allowedOrigins: ["*"]` combined with
`allowCredentials: true` is rejected by all modern browsers — credential requests to wildcard
origins are prohibited by the CORS spec. An invalid ISO country code in geo restrictions is
silently ignored by CDN providers — the restriction appears configured but never actually
applies. A WAF rule without an id cannot be correlated in audit logs — you cannot identify
which rule blocked a legitimate request. This compiler enforces all of these constraints before
emitting an artifact.

## Invariants

| Code  | Gate                    | What It Enforces |
|-------|-------------------------|------------------|
| EP001 | spec-valid              | `edge-policy-spec.json` exists, is valid JSON; `name` and `rules` (non-empty) are declared |
| EP002 | rate-limits-defined     | Every rule declares `rateLimit` with `requestsPerSecond` or `requestsPerMinute` (overridable with `skipRateLimitRequirement: true`) |
| EP003 | cors-headers-valid      | `allowedOrigins` non-empty; `*` + `allowCredentials` rejected; `allowedMethods` uses valid HTTP verbs (skipped if no cors block) |
| EP004 | waf-rules-valid         | Every WAF rule has `id`, `match`, and a valid `action`; `waf.mode` is `detection` or `prevention` (skipped if no waf block) |
| EP005 | geo-restrictions-valid  | All country codes match `[A-Z]{2}` (ISO 3166-1 alpha-2); `allowlist` and `denylist` are mutually exclusive (skipped if no geoRestrictions) |
| EP006 | no-todos                | `edge-policy-spec.json` contains no `TODO`, `FIXME`, `HACK`, `XXX`, or `PLACEHOLDER` |
| EP007 | contract-edge-policy    | Every rule has `name` or `match`; `requestsPerSecond` > 0; policy-level `name` declared |

## Required Output Files

- `edge-policy-spec.json` — author-maintained edge policy declaration
- `edge-policy-artifact.json` — generated by the compiler on full gate pass

## edge-policy-spec.json Structure

```json
{
  "name": "api-edge-policy",
  "rules": [
    {
      "name": "public-api",
      "match": "/api/v1/*",
      "rateLimit": {
        "requestsPerSecond": 100,
        "requestsPerMinute": 5000
      }
    },
    {
      "name": "auth-endpoint",
      "match": "/auth/*",
      "rateLimit": { "requestsPerSecond": 10 }
    }
  ],
  "cors": {
    "allowedOrigins":  ["https://app.example.com", "https://admin.example.com"],
    "allowedMethods":  ["GET", "POST", "PUT", "DELETE", "OPTIONS"],
    "allowedHeaders":  ["Authorization", "Content-Type"],
    "allowCredentials": true
  },
  "waf": {
    "mode": "prevention",
    "rules": [
      {
        "id": "block-sqli",
        "match": "(?i)(union|select|drop|insert|delete)",
        "action": "block"
      },
      {
        "id": "challenge-bots",
        "match": "User-Agent: (curl|wget|python-requests)",
        "action": "challenge"
      }
    ]
  },
  "geoRestrictions": {
    "denylist": ["KP", "IR", "CU"]
  }
}
```

## Field Reference

| Field                              | Required    | Notes |
|------------------------------------|-------------|-------|
| `name`                             | yes (EP001) | Policy identifier for audit logs |
| `rules`                            | yes (EP001) | Non-empty array of routing/rate-limit rules |
| `rules[].name`                     | yes (EP007) | Rule identifier — or provide `match` |
| `rules[].match`                    | yes (EP007) | URL pattern to match — or provide `name` |
| `rules[].rateLimit`                | yes (EP002) | Rate limit configuration |
| `rules[].rateLimit.requestsPerSecond` | conditional | Positive number |
| `rules[].rateLimit.requestsPerMinute` | conditional | Alternative rate unit |
| `skipRateLimitRequirement`         | no          | `true` to exempt all rules from EP002 |
| `cors.allowedOrigins`              | yes (EP003) | Non-empty array; avoid `["*"]` with `allowCredentials` |
| `cors.allowedMethods`              | no          | Array of HTTP methods |
| `cors.allowCredentials`            | no          | `true` requires explicit origins (not `*`) |
| `waf.mode`                         | no (EP004)  | `detection` (log only) or `prevention` (block) |
| `waf.rules[].id`                   | yes (EP004) | Unique identifier for audit correlation |
| `waf.rules[].match`                | yes (EP004) | Match expression (regex or condition) |
| `waf.rules[].action`               | yes (EP004) | See WAF Action Reference |
| `geoRestrictions.allowlist`        | conditional | Permit only listed countries — exclusive with `denylist` |
| `geoRestrictions.denylist`         | conditional | Block listed countries — exclusive with `allowlist` |

## WAF Action Reference

| Action      | Effect |
|-------------|--------|
| `allow`     | Permit the request — bypasses other WAF rules |
| `block`     | Reject the request with 403 |
| `challenge` | Present a CAPTCHA or JS challenge |
| `log`       | Log the request and pass it through |
| `redirect`  | Redirect to a configured URL |

## Geo Restriction Modes

| Mode        | Behaviour |
|-------------|-----------|
| `allowlist` | Only allow traffic from listed country codes |
| `denylist`  | Block traffic from listed country codes |

Country codes must be ISO 3166-1 alpha-2: two uppercase letters (`US`, `GB`, `DE`, `JP`).

## Error Codes

| Code  | Trigger | Fix |
|-------|---------|-----|
| EP001 | `edge-policy-spec.json` missing | Create with `name` and `rules: [...]` |
| EP001 | `rules: []` | Add at least one rule |
| EP001 | Missing `name` field | Add `"name": "my-edge-policy"` |
| EP002 | Rule has no `rateLimit` | Add `"rateLimit": { "requestsPerSecond": 100 }` |
| EP002 | `rateLimit` has neither `requestsPerSecond` nor `requestsPerMinute` | Add at least one rate value |
| EP003 | `allowedOrigins: []` | Add at least one origin, or `["*"]` for public APIs |
| EP003 | `allowedOrigins: ["*"]` + `allowCredentials: true` | List specific origins — wildcard + credentials is rejected by browsers |
| EP003 | `allowedMethods: ["CONNECT"]` | Use standard HTTP verbs: GET, POST, PUT, PATCH, DELETE, OPTIONS, HEAD |
| EP004 | WAF rule missing `id` | Add `"id": "rule-name"` to identify the rule in audit logs |
| EP004 | WAF rule missing `match` | Add `"match": "..."` — without match, the rule never triggers |
| EP004 | `action: "deny"` | Use `"block"` — `"deny"` is not a recognised action |
| EP004 | `waf.mode: "active"` | Use `"detection"` or `"prevention"` |
| EP005 | `denylist: ["Iran"]` | Use ISO codes: `["IR"]` — country names are silently ignored |
| EP005 | Both `allowlist` and `denylist` declared | Choose one mode — they are mutually exclusive |
| EP006 | `"match": "TODO"` in spec | Write a real match expression |
| EP007 | Rule has no `name` and no `match` | Add at least one — cannot audit which rule matched without identification |
| EP007 | `requestsPerSecond: 0` | Must be > 0 — a zero rate blocks all traffic |
