# Security Scan Pipeline — Implementation Guide

## Purpose

A scanner without a `failOn` threshold runs and reports — but never fails the pipeline.
Vulnerabilities appear in reports while deployments continue unblocked. `ignoreAll: true` on
a scanner disables all its checks — the pipeline runs green while every vulnerability is
silently suppressed. Without a defined output path, scan results are printed to stdout and lost
— findings cannot be compared across releases or uploaded to a security dashboard. An image
scanner without SAST means container CVEs are caught but code-level injection vulnerabilities
are not. A SAST scanner without image scanning means source code is reviewed but deployed
container images with known CVEs are not. This compiler enforces both coverage and correctness.

## Invariants

| Code  | Gate                    | What It Enforces |
|-------|-------------------------|------------------|
| SS001 | spec-valid              | `security-scan-spec.json` exists, is valid JSON; `name` and `scanners` (non-empty) are declared |
| SS002 | scanners-known          | Every scanner `type` is in the recognised allowlist |
| SS003 | severity-thresholds-set | Every scanner declares `failOn` with a recognised severity — without it the scanner never fails the pipeline |
| SS004 | no-ignore-all           | No scanner may use `ignoreAll: true` or `ignoreVulns: ["*"]`; `globalIgnore: true` is also prohibited |
| SS005 | report-output-defined   | `output.path` and `output.format` must be declared — results without a path are lost |
| SS006 | no-todos                | `security-scan-spec.json` contains no `TODO`, `FIXME`, `HACK`, `XXX`, or `PLACEHOLDER` |
| SS007 | contract-security-scan  | At least one image scanner (trivy/grype/clair/snyk) and at least one SAST scanner (semgrep/bandit/gosec/sonarqube) are required |

## Required Output Files

- `security-scan-spec.json` — author-maintained scan pipeline declaration
- `security-scan-artifact.json` — generated by the compiler on full gate pass

## security-scan-spec.json Structure

```json
{
  "name": "main-security-pipeline",
  "scanners": [
    {
      "type": "trivy",
      "failOn": "critical",
      "ignoreVulns": ["CVE-2021-44228"]
    },
    {
      "type": "semgrep",
      "failOn": "high",
      "config": "p/owasp-top-ten"
    },
    {
      "type": "checkov",
      "failOn": "high"
    }
  ],
  "output": {
    "path": ".ogu/security/scan-results.sarif",
    "format": "sarif"
  }
}
```

## Field Reference

| Field                  | Required    | Notes |
|------------------------|-------------|-------|
| `name`                 | yes (SS001) | Pipeline identifier |
| `scanners`             | yes (SS001) | Non-empty array of scanner configurations |
| `scanners[].type`      | yes (SS002) | Must be a recognised scanner type |
| `scanners[].failOn`    | yes (SS003) | Severity threshold — pipeline fails if this level or above is found |
| `scanners[].ignoreAll` | no          | Must not be `true` (SS004) |
| `scanners[].ignoreVulns` | no         | Array of specific CVE IDs to skip — must not include `"*"` |
| `output`               | yes (SS005) | Report output configuration |
| `output.path`          | yes (SS005) | File path for the report |
| `output.format`        | yes (SS005) | Report format — see format reference |
| `globalIgnore`         | no          | Must not be `true` (SS004) |
| `skipImageScan`        | no          | `true` to exempt from image scanner requirement (SS007) |
| `skipSAST`             | no          | `true` to exempt from SAST scanner requirement (SS007) |

## Scanner Reference

| Type          | Category    | Detects |
|---------------|-------------|---------|
| `trivy`       | Image/IaC   | Container CVEs, misconfigurations |
| `snyk`        | Image/SCA   | Container CVEs, dependency vulnerabilities |
| `grype`       | Image       | Container CVEs |
| `clair`       | Image       | Container CVEs |
| `semgrep`     | SAST        | Code-level vulnerabilities, OWASP patterns |
| `bandit`      | SAST        | Python security issues |
| `gosec`       | SAST        | Go security issues |
| `sonarqube`   | SAST        | Multi-language code quality and security |
| `checkov`     | IaC         | Terraform, CloudFormation misconfigurations |
| `tfsec`       | IaC         | Terraform security misconfigurations |
| `kubesec`     | IaC         | Kubernetes manifest security |
| `nuclei`      | DAST        | Web application vulnerabilities |
| `owasp-zap`   | DAST        | Dynamic application security testing |
| `nikto`       | DAST        | Web server misconfigurations |

## Severity Reference (SS003 failOn)

| Value      | Meaning |
|------------|---------|
| `critical` | Fail only on critical findings — most permissive |
| `high`     | Fail on high and above — recommended for production |
| `medium`   | Fail on medium and above |
| `low`      | Fail on any finding — strictest threshold |
| `info`     | Fail on informational and above |

## Report Format Reference (SS005)

| Format      | Use Case |
|-------------|----------|
| `sarif`     | GitHub Code Scanning, Azure DevOps, VS Code — recommended |
| `json`      | Programmatic processing and dashboards |
| `junit`     | CI/CD test result display |
| `html`      | Human-readable reports |
| `cyclonedx` | Software Bill of Materials (SBOM) |
| `table`     | Terminal output for local review |

## Error Codes

| Code  | Trigger | Fix |
|-------|---------|-----|
| SS001 | `security-scan-spec.json` missing | Create with `name` and `scanners: [...]` |
| SS001 | `scanners: []` | Add at least one scanner |
| SS002 | `type: "pentest"` | Use a recognised type: trivy, snyk, semgrep, etc. |
| SS002 | `type: "sast"` (category, not tool) | Use specific tool name: `semgrep`, `bandit`, or `gosec` |
| SS003 | Scanner missing `failOn` | Add `"failOn": "high"` to enable pipeline failure on findings |
| SS003 | `failOn: "urgent"` | Use `"critical"`, `"high"`, `"medium"`, `"low"`, or `"info"` |
| SS004 | `ignoreAll: true` on a scanner | Remove `ignoreAll` — use `ignoreVulns: ["CVE-XXXX-YYYY"]` for specific exclusions |
| SS004 | `ignoreVulns: ["*"]` | Replace with specific CVE IDs you have accepted the risk for |
| SS004 | `globalIgnore: true` | Remove entirely — this disables all scanners |
| SS005 | No `output` block | Add `"output": { "path": "security-report.sarif", "format": "sarif" }` |
| SS005 | `output.format: "pdf"` | Use `sarif`, `json`, `junit`, `html`, `table`, or `cyclonedx` |
| SS006 | `"failOn": "TODO"` | Set a real severity level |
| SS007 | No image scanner | Add `trivy`, `grype`, `clair`, or `snyk` scanner |
| SS007 | No SAST scanner | Add `semgrep`, `bandit`, `gosec`, or `sonarqube` scanner |
