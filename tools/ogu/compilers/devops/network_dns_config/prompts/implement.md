# Network DNS Config Compiler — Implementation Guide

## Purpose

Define DNS records that are correct, uniquely identifiable, and safe to propagate. A CNAME
at the zone apex is a protocol violation that breaks email delivery (`MX` resolution fails
when the apex is a CNAME). A TTL of 30 seconds floods authoritative servers with queries.
A TTL of 48 hours means a botched record change takes two days to fix in production. An
undeclared `owner` means no one is accountable when DNS changes go wrong. This compiler
enforces all of these constraints before emitting an artifact.

## Invariants

| Code   | Gate              | What It Enforces |
|--------|-------------------|------------------|
| DNS001 | spec-valid        | `dns-config-spec.json` exists, is valid JSON; `records` is non-empty; every record has `hostname`, `type` (from allowed enum), and `target` |
| DNS002 | hostnames-fqdn    | All hostnames are valid DNS labels; absolute hostnames (FQDN) end with a dot; no label starts or ends with a hyphen |
| DNS003 | hostnames-unique  | No two records share the same `hostname` + `type` combination |
| DNS004 | tls-host-match    | Every hostname in `spec.tls` matches at least one DNS record (skipped when `tls` is absent) |
| DNS005 | ttl-valid         | TTL values are integers within `[min, max]`; defaults: min=60s, max=86400s; configurable via `spec.ttlPolicy` |
| DNS006 | targets-resolve   | CNAME targets do not create loops; CNAME targets that are apex names are flagged (skipped when no CNAMEs) |
| DNS007 | no-todos          | `dns-config-spec.json` contains no `TODO`, `FIXME`, `HACK`, `XXX`, or `PLACEHOLDER` markers |
| DNS008 | contract-dns-config | `environment` and `owner` must be declared; records without explicit TTL are flagged as advisory |

## Required Output Files

- `dns-config-spec.json` — DNS record declarations (environment, records, optional TLS)
- `dns-config-artifact.json` — generated by the compiler on full gate pass

## dns-config-spec.json Structure

```json
{
  "environment": "production",
  "zone": "example.com",
  "owner": "platform-team",
  "ttlPolicy": { "min": 60, "max": 3600 },
  "records": [
    { "hostname": "api.example.com",  "type": "A",     "target": "203.0.113.10", "ttl": 300 },
    { "hostname": "www.example.com",  "type": "CNAME", "target": "api.example.com.", "ttl": 600 },
    { "hostname": "example.com",      "type": "A",     "target": "203.0.113.10", "ttl": 3600 },
    { "hostname": "example.com",      "type": "MX",    "target": "10 mail.example.com.", "ttl": 3600 },
    { "hostname": "example.com",      "type": "TXT",   "target": "v=spf1 include:_spf.google.com ~all", "ttl": 3600 }
  ],
  "tls": [
    { "hostname": "api.example.com",  "provider": "letsencrypt" },
    { "hostname": "www.example.com",  "provider": "letsencrypt" }
  ]
}
```

## DNS Record Types Reference

| Type    | Use Case | Target Format |
|---------|----------|---------------|
| `A`     | Maps hostname to IPv4 address | `"203.0.113.10"` |
| `AAAA`  | Maps hostname to IPv6 address | `"2001:db8::1"` |
| `CNAME` | Alias to another hostname | `"api.example.com."` (trailing dot = FQDN) |
| `MX`    | Mail exchange server | `"10 mail.example.com."` (priority + hostname) |
| `TXT`   | Arbitrary text (SPF, DKIM, domain verification) | `"v=spf1 include:..."` |
| `NS`    | Nameserver delegation | `"ns1.example.com."` |
| `SRV`   | Service discovery | `"10 5 443 api.example.com."` |

## TTL Strategy

| Scenario | Recommended TTL |
|----------|-----------------|
| Active migration / cutover | 60–300s |
| Standard service record | 300–600s |
| Stable infrastructure (NS, MX) | 3600–86400s |
| Emergency (prepare before incident) | Drop to 60s 24h before planned change |

## Error Codes

| Code   | Trigger | Fix |
|--------|---------|-----|
| DNS001 | `dns-config-spec.json` missing | Create the file with `records` array |
| DNS001 | Record missing `type` | Add `type: "A"` (or AAAA/CNAME/TXT/MX/NS/SRV) |
| DNS001 | `type: "SPF"` | SPF is not a record type — use `type: "TXT"` with SPF content |
| DNS002 | Hostname with double dot `api..example.com` | Fix the hostname — labels cannot be empty |
| DNS003 | Two records both `hostname: "api.example.com", type: "A"` | Combine into one record, or use different hostnames |
| DNS004 | TLS entry for `api.example.com` but no matching DNS record | Add an A/CNAME record for `api.example.com`, or remove from `tls` |
| DNS005 | `ttl: 30` | Minimum TTL is 60s (or your `ttlPolicy.min`) |
| DNS005 | `ttl: 172800` | Maximum TTL is 86400s (24h) |
| DNS006 | CNAME points to itself | Change target to a different hostname |
| DNS008 | No `environment` | Add `environment: "production"` (or `"staging"`) |
| DNS008 | No `owner` | Add `owner: "platform-team"` |
| DNS008 | Records without TTL | Add explicit `ttl` to each record |
