# Connection Pool Config — Implementation Guide

## Purpose

Define a connection pool configuration that routes traffic safely and survives database failover.
A pool where `maxClientConn < poolSize` saturates immediately — every incoming client connection
is rejected before reaching the database. TLS disabled without justification transmits passwords
in plaintext over the network. An unrecognised `authType` causes PgBouncer to reject the entire
configuration at startup, taking down all database access. No `failoverPolicy` means a DB primary
failover requires a manual pool restart in the middle of an incident. This compiler enforces all
of these constraints before emitting an artifact.

## Invariants

| Code  | Gate                    | What It Enforces |
|-------|-------------------------|------------------|
| CP001 | spec-valid              | `connection-pool-spec.json` exists, is valid JSON; `pooler`, `maxClientConn`, `poolSize`, and `host` are declared |
| CP002 | limits-positive         | `maxClientConn`, `poolSize`, and `maxConnections` (when declared) are positive integers |
| CP003 | client-conn-sufficient  | `maxClientConn` >= `poolSize`; headroom < 10% of `maxClientConn` is flagged (overridable with `skipHeadroomCheck: true`) |
| CP004 | auth-tls-valid          | `authType` and `tlsMode`, when declared, use recognised enum values |
| CP005 | host-refs-declared      | `host` must reference a hostname or env var — not a literal IP address |
| CP006 | no-todos                | `connection-pool-spec.json` contains no `TODO`, `FIXME`, `HACK`, `XXX`, or `PLACEHOLDER` markers |
| CP007 | contract-connection-pool| `tlsMode: "disable"` requires `disableTlsJustification`; `failoverPolicy` must be declared |

## Required Output Files

- `connection-pool-spec.json` — author-maintained pool declaration
- `connection-pool-artifact.json` — generated by the compiler on full gate pass

## connection-pool-spec.json Structure

```json
{
  "pooler": "pgbouncer",
  "host": "db.internal",
  "maxClientConn": 100,
  "poolSize": 20,
  "authType": "scram-sha-256",
  "tlsMode": "verify-full",
  "failoverPolicy": "reconnect-on-error",
  "connectTimeout": 5000,
  "idleTimeout": 60000
}
```

## Field Reference

| Field                    | Required    | Notes |
|--------------------------|-------------|-------|
| `pooler`                 | yes (CP001) | Pool software identifier (pgbouncer, pgpool, etc.) |
| `host`                   | yes (CP001) | DB hostname — env var reference preferred over literal IP |
| `maxClientConn`          | yes (CP001) | Total concurrent client connections the pool accepts |
| `poolSize`               | yes (CP001) | Connections per pool to the backend database |
| `authType`               | no (CP004)  | See auth type reference |
| `tlsMode`                | no (CP004)  | See TLS mode reference |
| `failoverPolicy`         | yes (CP007) | How the pool handles DB primary failover |
| `disableTlsJustification`| conditional | Required when `tlsMode: "disable"` |
| `skipHeadroomCheck`      | no          | `true` to disable the 10% headroom warning |

## Auth Type Reference

| Type           | Description |
|----------------|-------------|
| `scram-sha-256`| Recommended — strongest password authentication |
| `md5`          | Legacy password authentication — weaker than SCRAM |
| `trust`        | No password — only for local sockets, never network |
| `peer`         | OS user matches DB user — local only |
| `cert`         | TLS client certificate authentication |
| `password`     | Cleartext password — only over TLS |

## TLS Mode Reference

| Mode          | Description |
|---------------|-------------|
| `verify-full` | Recommended — verifies certificate AND hostname |
| `verify-ca`   | Verifies certificate authority but not hostname |
| `require`     | Requires TLS but does not verify certificate |
| `prefer`      | TLS if available, plaintext fallback |
| `disable`     | No TLS — credentials sent in plaintext |

## Error Codes

| Code  | Trigger | Fix |
|-------|---------|-----|
| CP001 | `connection-pool-spec.json` missing | Create the file with `pooler`, `maxClientConn`, `poolSize`, `host` |
| CP002 | `poolSize: 0` | Must be a positive integer — use at least `1` |
| CP002 | `maxClientConn: 10.5` | Must be an integer, not a float |
| CP003 | `maxClientConn: 10`, `poolSize: 20` | maxClientConn must be >= poolSize — swap the values or increase maxClientConn |
| CP003 | `maxClientConn: 100`, `poolSize: 92` | Only 8% headroom — add `skipHeadroomCheck: true` if intentional |
| CP004 | `authType: "sha256"` | Use `"scram-sha-256"` |
| CP004 | `tlsMode: "required"` | Use `"require"` (not `"required"`) |
| CP007 | `tlsMode: "disable"` without `disableTlsJustification` | Add `disableTlsJustification: "Internal k8s pod-to-pod traffic only"` |
| CP007 | No `failoverPolicy` | Add `failoverPolicy: "reconnect-on-error"` |
