# Cost Tagging Policy — Implementation Guide

## Purpose

A tag key with invalid characters is silently truncated or rejected by AWS, GCP, and Azure —
the tag appears configured but is never stored, making cost attribution impossible. A
`defaultValue` not in `allowedValues` creates an impossible constraint — no deployment can
satisfy it. A `requiredTags` array without team, service, or cost-center tags means FinOps
cannot answer "which team is responsible for this $50,000 monthly spend." An enforcement mode
of `enforce` without `enforcementTargets` means the policy attempts to block every resource
creation across the entire cloud account. Duplicate tag keys in the policy create ambiguous
enforcement — two conflicting rules for the same key, one of which silently wins. This compiler
enforces all of these constraints before emitting an artifact.

## Invariants

| Code  | Gate                    | What It Enforces |
|-------|-------------------------|------------------|
| CT001 | spec-valid              | `cost-tagging-spec.json` exists, is valid JSON; `organization` and `requiredTags` (non-empty) are declared |
| CT002 | required-tags-defined   | Every tag has `key` and `description`; common billing tags (team/service/environment/cost-center) should be present |
| CT003 | tag-values-valid        | Tag keys match `[a-zA-Z0-9_\-:/.]{1,128}`; `defaultValue` must be in `allowedValues` when both are declared |
| CT004 | resource-types-covered  | When `resourceTypes` is declared, compute/storage/network categories must be covered (skipped when absent) |
| CT005 | enforcement-mode-set    | `enforcementMode` must be one of: `audit`, `enforce`, `warn` |
| CT006 | no-todos                | `cost-tagging-spec.json` contains no `TODO`, `FIXME`, `HACK`, `XXX`, or `PLACEHOLDER` |
| CT007 | contract-cost-tagging   | No duplicate tag keys; `enforcementMode=enforce` requires `enforcementTargets` |

## Required Output Files

- `cost-tagging-spec.json` — author-maintained tagging policy declaration
- `cost-tagging-artifact.json` — generated by the compiler on full gate pass

## cost-tagging-spec.json Structure

```json
{
  "organization": "acme-corp",
  "enforcementMode": "enforce",
  "enforcementTargets": ["aws_instance", "aws_rds_instance", "aws_s3_bucket"],
  "resourceTypes": ["compute", "storage", "network", "database"],
  "requiredTags": [
    {
      "key": "team",
      "description": "Owning team responsible for this resource",
      "allowedValues": ["platform", "payments", "data", "security"],
      "defaultValue": "platform"
    },
    {
      "key": "service",
      "description": "Service name that this resource belongs to"
    },
    {
      "key": "environment",
      "description": "Deployment environment",
      "allowedValues": ["development", "staging", "production"],
      "defaultValue": "development"
    },
    {
      "key": "cost-center",
      "description": "Finance cost center code for billing attribution",
      "defaultValue": "CC-0000"
    }
  ]
}
```

## Field Reference

| Field                 | Required    | Notes |
|-----------------------|-------------|-------|
| `organization`        | yes (CT001) | Org identifier for the policy |
| `requiredTags`        | yes (CT001) | Non-empty array of tag definitions |
| `requiredTags[].key`  | yes (CT002) | Tag key — max 128 chars, alphanumeric + `_`, `-`, `:`, `/`, `.` |
| `requiredTags[].description` | yes (CT002) | Human-readable explanation |
| `requiredTags[].allowedValues` | no        | Restrict to specific values |
| `requiredTags[].defaultValue`  | no        | Must be in `allowedValues` when both are declared (CT003) |
| `enforcementMode`     | yes (CT005) | See enforcement mode reference |
| `enforcementTargets`  | conditional | Required when `enforcementMode: "enforce"` (CT007) |
| `resourceTypes`       | no          | Declare to enable resource category coverage check (CT004) |
| `skipBillingTagCheck` | no          | `true` to exempt from CT002 billing tag recommendations |
| `skipResourceTypeCoverage` | no     | `true` to exempt from CT004 category coverage check |

## Enforcement Mode Reference

| Mode      | Effect | When to Use |
|-----------|--------|-------------|
| `audit`   | Log violations but allow resource creation | Initial rollout — identify gaps without blocking |
| `warn`    | Generate alerts but allow resource creation | Soft enforcement during transition period |
| `enforce` | Block resource creation when tags are missing | Full compliance — requires `enforcementTargets` |

## Tag Key Naming Rules (CT003)

| Allowed Characters | Example |
|---------------------|---------|
| `a-z`, `A-Z`, `0-9` | `team`, `Service` |
| `_` (underscore)    | `cost_center` |
| `-` (hyphen)        | `cost-center` |
| `:` (colon)         | `aws:team` |
| `/` (slash)         | `company/team` |
| `.` (period)        | `corp.team` |

Maximum length: 128 characters. Minimum: 1 character.

## Error Codes

| Code  | Trigger | Fix |
|-------|---------|-----|
| CT001 | `cost-tagging-spec.json` missing | Create with `organization` and `requiredTags: [...]` |
| CT001 | `requiredTags: []` | Add at least one tag definition |
| CT001 | Missing `organization` field | Add `"organization": "my-company"` |
| CT002 | Tag missing `key` | Add `"key": "team"` to the tag entry |
| CT002 | Tag missing `description` | Add `"description": "Team that owns this resource"` |
| CT002 | Missing recommended billing tags | Add `team`, `service`, `environment`, `cost-center` entries, or set `skipBillingTagCheck: true` |
| CT003 | `key: "team name"` (space) | Use `"team-name"` or `"team_name"` — spaces are not allowed |
| CT003 | `key` exceeds 128 chars | Shorten the tag key |
| CT003 | `defaultValue: "prod"` not in `allowedValues: ["production"]` | Either add `"prod"` to allowedValues or change defaultValue to `"production"` |
| CT004 | `resourceTypes` declared but missing `"compute"` | Add a compute resource type (e.g. `"aws_instance"`) or set `skipResourceTypeCoverage: true` |
| CT004 | `resourceTypes` declared but missing `"storage"` | Add `"aws_s3_bucket"` or similar storage type |
| CT004 | `resourceTypes` declared but missing `"network"` | Add `"aws_vpc"` or similar network type |
| CT005 | No `enforcementMode` | Add `"enforcementMode": "audit"` to start, then promote to `"enforce"` |
| CT005 | `enforcementMode: "block"` | Use `"enforce"` — `"block"` is not a valid mode |
| CT006 | `"key": "TODO"` | Replace with a real tag key |
| CT007 | Duplicate `key: "team"` entries | Each key must appear once — remove the duplicate |
| CT007 | `enforcementMode: "enforce"` without `enforcementTargets` | Add `"enforcementTargets": ["aws_instance", "aws_rds_instance", ...]` |
