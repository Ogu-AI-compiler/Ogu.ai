# Kustomize Overlay — Implementation Guide

## Purpose

Define a Kustomize overlay that applies to the correct environment namespace and builds a complete
manifest. A `kustomization.yaml` with no `resources`, `bases`, or `components` builds nothing —
the apply appears successful while no workloads are updated. A patch without `target.kind` cannot
be matched to any resource — kustomize fails at apply time with a cryptic error. A `namespaceOverride`
of `"myapp-production"` applied to a `staging` overlay deploys resources into the wrong cluster
namespace with no runtime error. An image tag policy of `latest-allowed` silently changes behaviour
across environments when images are rebuilt. This compiler enforces all of these constraints before
emitting an artifact.

## Invariants

| Code  | Gate                   | What It Enforces |
|-------|------------------------|------------------|
| KO001 | spec-valid             | `kustomize-spec.json` exists, is valid JSON; `base` and `environment` are declared |
| KO002 | kustomization-valid    | `kustomization.yaml` exists and declares at least one of `resources`, `bases`, or `components` |
| KO003 | patches-resolve        | Every patch in `spec.patches` with a `target` must include `target.kind` — kustomize cannot match a patch without a kind |
| KO004 | no-duplicate-resources | No two entries in `spec.resources` share the same `kind`/`name` combination |
| KO005 | namespace-matches-env  | When `namespaceOverride` is declared, it must contain `spec.environment` as a substring (overridable with `allowNamespaceMismatch: true`) |
| KO006 | no-todos               | `kustomize-spec.json` contains no `TODO`, `FIXME`, `HACK`, `XXX`, or `PLACEHOLDER` markers |
| KO007 | contract-kustomize     | `imageTagPolicy` must be declared and must be `digest`, `semver`, or `latest-allowed` |

## Required Output Files

- `kustomize-spec.json` — author-maintained overlay declaration
- `kustomization.yaml` — Kustomize overlay file with resources/bases/components
- `kustomize-artifact.json` — generated by the compiler on full gate pass

## kustomize-spec.json Structure

```json
{
  "base": "../../base",
  "environment": "production",
  "imageTagPolicy": "semver",
  "namespaceOverride": "myapp-production",
  "resources": [
    { "kind": "Deployment", "name": "api-gateway" },
    { "kind": "Service",    "name": "api-gateway" }
  ],
  "patches": [
    {
      "path": "patches/replicas.yaml",
      "target": { "kind": "Deployment", "name": "api-gateway" }
    },
    {
      "path": "patches/resources.yaml",
      "target": { "kind": "Deployment", "name": "api-gateway" }
    }
  ],
  "images": [
    { "name": "api-gateway", "newTag": "2.1.4" }
  ]
}
```

## kustomization.yaml Structure

```yaml
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization

bases:
  - ../../base

namespace: myapp-production

resources:
  - deployment.yaml
  - service.yaml

patches:
  - path: patches/replicas.yaml
    target:
      kind: Deployment
      name: api-gateway

images:
  - name: api-gateway
    newTag: "2.1.4"
```

## Image Tag Policy Reference

| Policy           | Meaning | Use When |
|------------------|---------|----------|
| `digest`         | All image references use SHA digest | Maximum reproducibility — same bytes every deploy |
| `semver`         | Image tags follow semantic versioning | Standard release workflows |
| `latest-allowed` | `:latest` tag is permitted with justification | Internal dev environments only |

## Error Codes

| Code  | Trigger | Fix |
|-------|---------|-----|
| KO001 | `kustomize-spec.json` missing | Create the file with `base` and `environment` |
| KO002 | `kustomization.yaml` not found | Create `kustomization.yaml` with `resources:` or `bases:` |
| KO002 | `kustomization.yaml` has no `resources`, `bases`, or `components` | Add a `resources:` section listing the base manifests |
| KO003 | `patches[].target` present but no `target.kind` | Add `target.kind: "Deployment"` (or the appropriate resource kind) |
| KO004 | Two resources both `kind: Deployment, name: api-gateway` | Remove the duplicate or rename one resource |
| KO005 | `environment: production`, `namespaceOverride: "myapp-staging"` | Change namespace to `myapp-production` or add `allowNamespaceMismatch: true` |
| KO007 | No `imageTagPolicy` | Add `imageTagPolicy: "semver"` (or `digest` or `latest-allowed`) |
| KO007 | `imageTagPolicy: "floating"` | Not recognised — use `digest`, `semver`, or `latest-allowed` |
