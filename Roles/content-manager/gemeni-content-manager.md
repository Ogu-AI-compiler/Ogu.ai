content-type-schemaName: Content Model CompilerFrequency: Per-Project (or per major feature)Input: UX wireframes, data requirements, and editorial needs.Output: JSON-based CMS Schema (e.g., Contentful/Sanity type definitions).Correctness Gates: _ Every field must have a defined validation rule (e.g., regex, min/max length).Schema must include a sys_slug field and a sys_metadata object.Dependencies: react-page, ts-schema.Downstream Consumers: content-entry-manifest, cms-field-mapping.Spec file: {"typeName": "article", "fields": [{"id": "title", "type": "string", "required": true}]}Error codes: CM101 (Missing Required System Field), CM102 (Cyclic Reference), CM103 (Invalid Validation Regex).Key invariant: No content type can exist without a unique identifier and a human-readable label.Safe default: Generic "Page" type with title and body fields.2. editorial-workflow-specName: Workflow State CompilerFrequency: Per-ProjectInput: Editorial roles, legal approval requirements, and publishing levels.Output: Workflow State Machine Manifest (JSON/XState).Correctness Gates: _ Every "Published" state must have an "Archive" transition.Regulated content types must include a "Legal Review" node.Dependencies: None.Downstream Consumers: campaign-content-bundle, legal-approval-manifest.Spec file: {"states": ["draft", "review", "legal", "published"], "roles": {"legal": ["editor-in-chief"]}}Error codes: CM201 (Unreachable State), CM202 (Missing Terminal State), CM203 (Invalid Role Transition).Key invariant: A document cannot transition to "Published" without satisfying all previous mandatory approval nodes.Safe default: Simple Draft -> Published flow.3. taxonomy-manifestName: Taxonomy & Tagging CompilerFrequency: Per-ProjectInput: SEO keyword research, category hierarchy, and navigation intent.Output: Structured Tagging Policy (JSON/SKOS).Correctness Gates: _ Every category must have a unique URL slug.Hierarchy depth cannot exceed 4 levels.Dependencies: None.Downstream Consumers: content-entry-manifest, internal-link-map.Spec file: {"categories": [{"id": "tech", "sub": ["ai", "devops"]}], "enforceTags": true}Error codes: CM301 (Duplicate Slug), CM302 (Max Depth Exceeded), CM303 (Orphaned Category).Key invariant: All tags used in content must exist within the approved taxonomy manifest.Safe default: Flat "Uncategorized" list.4. content-entry-manifestName: Content Object CompilerFrequency: DailyInput: Raw copy, images, content-type-schema, and taxonomy-manifest.Output: Validated Structured Content Object (JSON).Correctness Gates: _ Content must satisfy all "Required" fields in the content-type-schema.All internal links must resolve to valid route artifacts.Dependencies: content-type-schema, taxonomy-manifest, api-route.Downstream Consumers: CMS API, seo-metadata-spec.Spec file: {"type": "article", "values": {"title": "Hello World", "tags": ["tech"]}}Error codes: CM401 (Field Validation Failure), CM402 (Broken Internal Link), CM403 (Invalid Taxonomy Reference).Key invariant: A content object must exactly match the shape defined by its associated schema.Safe default: Draft object with placeholder text.5. seo-metadata-specName: SEO & Rich Results CompilerFrequency: DailyInput: content-entry-manifest, URL policy, and keyword targets.Output: SEO Metadata Manifest (JSON-LD / Meta Tags).Correctness Gates: _ Title tag must be between 30 and 60 characters.Meta description must be between 70 and 160 characters.Canonical URL must not point to a redirect.Dependencies: content-entry-manifest, openapi-spec.Downstream Consumers: react-page, sitemap-generator.Spec file: {"canonical": "https://site.com/p", "ogTitle": "...", "schemaOrg": "Article"}Error codes: CM501 (Title Too Long), CM502 (Canonical Conflict), CM503 (Missing Rich Result Data).Key invariant: Every published URL must have a non-null canonical tag.Safe default: Use Page Title as SEO Title; first paragraph as meta description.6. redirect-manifestName: URI Mapping CompilerFrequency: Daily / Per-ProjectInput: Old URL, New URL, and redirect type (301/302).Output: Redirect Manifest (JSON/Nginx Config).Correctness Gates: _ Must not create redirect chains (A -> B -> C).Destination must not be a 404.Dependencies: api-route.Downstream Consumers: react-page, Proxy/Load Balancer.Spec file: {"redirects": [{"from": "/old", "to": "/new", "code": 301}]}Error codes: CM601 (Redirect Loop), CM602 (Redirect Chain), CM603 (Destination 404).Key invariant: A redirect must always point to a terminal active route.Safe default: No redirect; return 404.7. media-asset-policyName: Media Governance CompilerFrequency: DailyInput: Raw assets (Image/Video) and source credits.Output: Media Metadata Spec (JSON).Correctness Gates: _ Every image must have non-empty Alt Text.Every asset must have a defined "Usage Rights" status.Dependencies: a11y-test.Downstream Consumers: content-entry-manifest, react-component.Spec file: {"assetId": "img_01", "alt": "A sunset over the city", "credit": "John Doe"}Error codes: CM701 (Missing Alt Text), CM702 (Missing Attribution), CM703 (File Too Large).Key invariant: No media can be published without an accessibility label (alt text).Safe default: Descriptive filename as alt text; "Internal" as credit.8. campaign-content-bundleName: Campaign Distribution CompilerFrequency: Per-CampaignInput: Launch date, variant specs (A/B), and feature-flag IDs.Output: Variant Scheduling Manifest (JSON).Correctness Gates: _ Campaign end date must be after start date.Variant IDs must map 1:1 to feature-flag keys.Dependencies: feature-flag, content-entry-manifest.Downstream Consumers: react-page, analytics-event.Spec file: {"campaignId": "black-friday", "variants": [{"flag": "BF_V1", "content": "..."}]}Error codes: CM801 (Scheduling Conflict), CM802 (Flag Mismatch), CM803 (Incomplete Variant Content).Key invariant: All campaign variants must be fully populated with content before the start date.Safe default: Show "Control" variant to all users.9. stale-content-reportName: Content Audit CompilerFrequency: DailyInput: Last updated date, product spec changes, and performance data.Output: Stale Content Manifest / Audit Log (JSON).Correctness Gates: \* Flag content older than 180 days for review.Flag content mentioning deprecated product routes.Dependencies: content-entry-manifest, api-route.Downstream Consumers: editorial-workflow-spec (Task generation).Spec file: {"pageId": "about-us", "status": "stale", "reason": "Old route mentioned"}Error codes: CM901 (Deprecation Found), CM902 (Outdated Data), CM903 (Review Overdue).Key invariant: Any content referencing a removed api-route must be flagged as "Stale".Safe default: Mark all content as "Current".Recommended Build OrderTo implement the Content Manager compiler network, follow this dependency priority:Tier 1: Foundation (Structural Governance)content-type-schema: Required to define the shape of everything else.editorial-workflow-spec: Establishes the rules for moving from draft to live.taxonomy-manifest: Establishes the classification system for navigation and discovery.Tier 2: Execution (Operational Delivery)content-entry-manifest: The primary "daily" compiler for creating the core artifacts.media-asset-policy: Ensures all injected media meets standards.seo-metadata-spec: Optimizes the entries for external discovery.Tier 3: Optimization & Lifecycle (Management)internal-link-map: Validates the relationship between various entries.redirect-manifest: Handles URI lifecycle.campaign-content-bundle: Manages complex time-based or variant-based delivery.stale-content-report: Closes the loop on content maintenance.Why this order?You cannot produce a Content Entry without a Schema to validate against. You cannot produce a Campaign Bundle without existing Content Entries and Workflow Rules. The Tier 1 compilers provide the "Laws," Tier 2 provides the "Actions," and Tier 3 provides the "Optimization."
