Breakdown1. ui-token-systemName: Design Token CompilerFrequency: Per-Project (Updated as needed)Input: Brand color values, base spacing unit, primitive radius values.Output: tokens.json (W3C Design Token format).Correctness Gates:Binary check: All color values must meet WCAG 2.1 AA contrast ratios against defined background tokens.Binary check: All spacing values must be multiples of the base unit (e.g., 4px).Dependencies: None.Downstream Consumers: ui-theme-manifest, react-component, react-page.Spec File: {"primitives": {"blue-500": "#007BFF"}, "semantic": {"action-primary": "{blue-500}"}}Error Codes: UI101 (Contrast Failure), UI102 (Non-Scale Value), UI103 (Circular Reference).Key Invariant: Every primitive token must have a unique value and a semantic alias.Safe Default: System-standard fallback (e.g., 8px spacing, black/white grayscale).2. ui-theme-manifestName: Theme Logic CompilerFrequency: Per-ProjectInput: ui-token-system, Dark/Light/High-Contrast intent.Output: themes.json (Mapping of semantic tokens to modes).Correctness Gates:Binary check: Every semantic color token must have a mapping for every defined mode (Dark/Light).Binary check: High-contrast mode must have 0% opacity tokens.Dependencies: ui-token-system.Downstream Consumers: react-page, ui-component-variant.Spec File: {"light": {"bg-surface": "{gray-50}"}, "dark": {"bg-surface": "{gray-900}"}}Error Codes: UI201 (Missing Mode Mapping), UI202 (Invalid Contrast in Dark Mode).Key Invariant: Switching a theme must not change the semantic token name, only the underlying primitive value.Safe Default: Light mode only.3. ui-typography-scaleName: Typography Scale CompilerFrequency: Per-ProjectInput: Targeted device types (Mobile/Web), i18n requirements.Output: typography.json (Font-face, scale, line-height, and tracking).Correctness Gates:Binary check: Line-height must be $\geq 1.5$ for body text tokens.Binary check: Every font size must have a fallback for RTL/Expansion-heavy languages (e.g., German).Dependencies: i18n.Downstream Consumers: ui-content-hierarchy, react-component.Spec File: {"scales": {"base": "16px", "ratio": 1.25}, "rules": {"h1": {"size": "{step-5}", "weight": 700}}}Error Codes: UI301 (Line-height Too Tight), UI302 (Missing i18n Fallback), UI303 (Font-weight Mismatch).Key Invariant: The type scale must be mathematically derived from a single base unit and ratio.Safe Default: System sans-serif, 16px base, 1.5 line-height.4. ui-layout-gridName: Responsive Grid CompilerFrequency: Per-FeatureInput: Breakpoint definitions (Mobile/Tablet/Desktop).Output: layout_spec.json (Columns, gutters, margins per breakpoint).Correctness Gates:Binary check: Grid margins must be $\geq$ the smallest spacing token.Binary check: Every breakpoint must have a defined behavior for RTL mirroring.Dependencies: ui-token-system.Downstream Consumers: react-page.Spec File: {"breakpoints": {"mobile": {"cols": 4, "gutter": "16px"}, "desktop": {"cols": 12}}}Error Codes: UI401 (Breakpoint Overlap), UI402 (Gutter Overflow), UI403 (RTL Inversion Missing).Key Invariant: The sum of columns, gutters, and margins must equal 100% of the viewport width.Safe Default: Single-column fluid layout with 16px margins.5. ui-component-variantName: Visual Variant CompilerFrequency: DailyInput: react-component prop definitions (e.g., size, color-intent, shape).Output: variant_matrix.json (Visual styling properties for every prop combination).Correctness Gates:Binary check: All variant colors must reference existing ui-theme-manifest tokens.Binary check: Variants with "destructive" intent must use the semantic danger token.Dependencies: react-component, ui-theme-manifest.Downstream Consumers: react-component (CSS/Style layer).Spec File: {"button": {"variants": {"primary": {"bg": "{action-primary}", "text": "{text-on-action}"}}}}Error Codes: UI501 (Unmapped Variant), UI502 (Token Reference Error), UI503 (Semantic Misuse).Key Invariant: Every prop defined in react-component must have a corresponding visual mapping in the variant matrix.Safe Default: "Primary" variant styling applied to all instances.6. ui-state-appearanceName: State Visual CompilerFrequency: DailyInput: ux-state-matrix (Loading, Error, Hover, Focus, Active).Output: state_visuals.json (Visual spec for interaction and data states).Correctness Gates:Binary check: "Focus" state must have a visible indicator with $\geq 3:1$ contrast against the component background.Binary check: Skeleton screens must match the layout geometry of the "Success" state.Dependencies: ux-state-matrix, ui-token-system.Downstream Consumers: react-component, a11y-test.Spec File: {"input": {"states": {"error": {"border": "{border-danger}"}, "focus": {"outline": "{focus-ring}"}}}}Error Codes: UI601 (Invisible Focus), UI602 (Skeleton Mismatch), UI603 (Missing Error Visual).Key Invariant: Every functional state (UX) must have a unique, perceivable visual change (UI).Safe default: Default browser focus ring; 50% opacity for disabled states.7. ui-motion-manifestName: Motion Logic CompilerFrequency: Per-ProjectInput: Transition types (Enter, Exit, Move), reduced-motion policy.Output: motion.json (Durations, Bezier curves, staggered delay rules).Correctness Gates:Binary check: All durations must be between 100ms and 500ms for UI feedback.Binary check: Every motion spec must have a prefers-reduced-motion override (e.g., opacity-only).Dependencies: ux-user-flow.Downstream Consumers: react-component, a11y-test.Spec File: {"easings": {"standard": "cubic-bezier(0.4, 0, 0.2, 1)"}, "durations": {"fast": "150ms"}}Error Codes: UI701 (Motion Too Slow), UI702 (Missing Reduced Motion), UI703 (Disorienting Curve).Key Invariant: Motion cannot be used as the only indicator of a state change.Safe Default: No animation (instant state change).8. ui-data-viz-specName: Visualization Stylist CompilerFrequency: Per-FeatureInput: ts-schema (data types), chart types (Bar, Line, Pie).Output: viz_theme.json (Categorical/Sequential color ramps, axis styling).Correctness Gates:Binary check: Categorical color ramps must be color-blind accessible (Protanopia/Deuteranopia).Binary check: Grid lines must be $\leq 1px$ and use the border-subtle token.Dependencies: ui-token-system, ts-schema.Downstream Consumers: react-component (Chart components).Spec File: {"charts": {"palette": ["{blue-500}", "{orange-500}", "{green-500}"], "axis": {"label-size": "{text-xs}"}}}Error Codes: UI801 (Inaccessible Palette), UI802 (Visual Noise - Too many grid lines), UI803 (Unlabeled Axis).Key Invariant: Visual encoding (color/size) must map 1:1 to data dimensions defined in the schema.Safe Default: Monochromatic grayscale chart.Recommended Build OrderThe UI Compiler Network follows a "Primitives-to-Implementation" dependency graph:ui-token-system (Foundation): Nothing can be styled without the basic unit system (colors, spacing).ui-theme-manifest & ui-typography-scale: Defines the semantic logic and global content appearance.ui-layout-grid: Establishes the spatial containers for the components.ui-component-variant: Applies the themes and tokens to the atomic component structures.ui-state-appearance: Layers interaction logic (UX) into visual feedback (UI).ui-motion-manifest & ui-data-viz-spec: Adds high-level polish and specific data-handling capabilities.ui-visual-baseline: Wraps everything in a regression-testing layer to ensure no future drift.Dependencies for First
